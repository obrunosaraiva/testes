Opções — PRD Generator

Escolha o provedor e cole a API key. As chaves ficam em chrome.storage.local, apenas na sua máquina.

Como usar

  1. Configure sua API key acima e salve.
  2. Clique no ícone da extensão na barra do Chrome.
  3. Responda as 8 perguntas rápidas sobre sua ideia.
  4. O PRD é gerado em Markdown — copie e cole no Claude Code.
