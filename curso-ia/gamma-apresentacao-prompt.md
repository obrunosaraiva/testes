# Prompt para Gerar a Apresentação no Gamma

> Cole o bloco abaixo diretamente no Gamma.app > "Generate" > "Paste text or outline"

---

## BLOCO PARA COLAR NO GAMMA

```

**"Criação Profissional com IA: Páginas, Copy, Imagens e Vídeos"**

Público: iniciantes que querem criar presença digital usando IA
Tom: direto, motivador, prático — sem jargão técnico
Estilo visual: moderno, dark mode ou gradiente vibrante, ícones minimalistas

Título: Criação Profissional com IA
```

## Configurações recomendadas no Gamma

Após colar o outline acima:

- **Theme:** Dark Gradient ou Vibrant — combina com o tom dinâmico da aula
- **Density:** Balanced (não sobrecarrega os slides)
- **Layout style:** Modern
- **Font pairing:** Sans-serif bold para títulos + regular para corpo
- **Accent color:** roxo + azul elétrico ou laranja + escuro

## Ajustes pós-geração

Após o Gamma gerar a apresentação, revise:

1. **Slide 7, 12, 14, 16** — os prompts de exercício: verifique se ficaram em caixa de destaque (code block ou callout)
2. **Slide 3** — grade de ferramentas: ajuste para que cada item tenha ícone visual
3. **Slides 9, 10, 11** — frameworks: peça ao Gamma para usar layout de "steps" ou "cards horizontais"
4. **Slide de capa** — adicione uma imagem de fundo gerada no Freepik ou Gemini para impacto visual
