# Criação Profissional com IA: Páginas, Copy, Imagens e Vídeos

> **Formato:** Aula única | **Nível:** Iniciantes | **Duração estimada:** 2h30

---

## Visão Geral

Nessa aula você vai aprender a criar uma presença digital completa do zero usando ferramentas de IA — sem precisar saber programar, sem precisar ser designer, sem precisar ser redator profissional.

**O que você vai criar ao final:**
- Uma página funcional no ar
- Textos persuasivos prontos para usar
- Imagens e ensaios fotográficos com qualidade profissional
- Vídeos para redes sociais ou apresentações

---

## Ferramentas que vamos usar

| Ferramenta | Para quê |
|---|---|
| **Lovable** | Criar páginas web completas com IA |
| **Claude Code** | Escrever copy, ajustar código, automatizar tarefas |
| **Gemini (Nano Banana)** | Geração de imagens e suporte criativo |
| **Freepik** | Imagens, mockups e ensaios fotográficos com IA |
| **+ Outras** | Ferramentas extras que aparecem no caminho |

## Estrutura da Aula

---

### Bloco 1 — Mentalidade: IA como Parceiro de Criação
**Duração: ~15 min**

**O que você vai aprender:**
- Como parar de usar IA como "buscador melhorado" e passar a usar como co-criador
- A diferença entre *prompt ruim* e *prompt que funciona*
- O fluxo completo de criação: ideia → página → conteúdo → imagens → vídeo

**Conceito principal:**
> A IA não vai substituir sua ideia — ela vai executar sua ideia mais rápido do que qualquer profissional.

**Exercício mental:**
- Pense em um projeto real que você quer criar (produto, serviço, portfólio, evento)
- Esse projeto vai ser o fio condutor de toda a aula

---

### Bloco 2 — Páginas com Lovable
**Duração: ~30 min**

**O que você vai aprender:**
- O que é o Lovable e por que ele mudou o jogo para quem não sabe programar
- Como descrever uma página para a IA e receber código pronto
- Como iterar: pedir ajustes, mudar cores, adicionar seções
- Como publicar a página no ar em minutos

**Passo a passo:**
1. Criar conta no Lovable
2. Descrever seu projeto em linguagem natural ("Quero uma landing page para...")
3. Revisar o resultado e pedir ajustes com prompts específicos
4. Conectar domínio ou usar o link gerado

**Dicas de prompt para Lovable:**
```
"Crie uma landing page para [produto/serviço].
Inclua: hero com CTA, seção de benefícios, depoimentos, FAQ e rodapé.
Tom: [profissional / descontraído / urgente].
Paleta de cores: [descreva ou informe um hex]."
```

**Erros comuns de iniciante:**
- Prompt vago demais ("faz uma página bonita")
- Não pedir a seção de CTA desde o início
- Não testar no mobile antes de publicar

---

### Bloco 3 — Copy com Claude Code
**Duração: ~30 min**

**O que você vai aprender:**
- Como usar o Claude para escrever copy que converte (não só "um texto qualquer")
- Frameworks de copy que a IA domina: AIDA, PAS, Before/After/Bridge
- Como adaptar o tom para diferentes canais: página, Instagram, e-mail, WhatsApp
- Como iterar o texto até ficar exatamente como você quer

**Passo a passo:**
1. Abrir o Claude Code (ou Claude.ai)
2. Descrever o produto/serviço com detalhes reais
3. Pedir versões diferentes com frameworks distintos
4. Combinar os melhores pedaços

**Template de prompt para copy:**
```
"Escreva uma copy para [produto/serviço].

Público-alvo: [descreva quem é]
Principal dor que resolve: [seja específico]
Principal transformação prometida: [resultado concreto]
Tom: [direto / empático / urgente / inspirador]
Formato: [headline + subtítulo + 3 bullets + CTA]

Use o framework PAS (Problema, Agitação, Solução)."
```

**Exercício prático:**
- Escrever a copy completa da página criada no Bloco 2
- Testar 3 headlines diferentes e escolher o mais forte

---

### Bloco 4 — Imagens e Ensaios Fotográficos
**Duração: ~35 min**

**Parte A — Freepik AI (20 min)**

**O que você vai aprender:**
- Como gerar imagens realistas para produtos, pessoas e cenários
- Como criar um "ensaio fotográfico" virtual sem contratar fotógrafo
- Como usar os templates e mockups do Freepik para apresentar seus produtos

**Passo a passo:**
1. Acessar o Freepik > Ferramentas de IA
2. Descrever a imagem com detalhes: ambiente, iluminação, estilo, sujeito
3. Gerar variações e selecionar as melhores
4. Usar mockups para simular produto físico

**Template de prompt para imagens:**
```
"[Sujeito] em [ambiente/cenário].
Estilo fotográfico: [editorial / comercial / lifestyle / produto].
Iluminação: [natural / estúdio / golden hour].
Ângulo: [frontal / 3/4 / aéreo].
Qualidade: alta resolução, fotorrealista."
```

**Parte B — Gemini Nano Banana (15 min)**

**O que você vai aprender:**
- Como usar o Gemini para gerar imagens com estilo específico
- Diferenças entre Freepik e Gemini: quando usar cada um
- Como combinar imagens geradas com seu layout do Lovable

**Quando usar Gemini vs Freepik:**
| Situação | Use |
|---|---|
| Precisa de foto realista de produto | Freepik |
| Precisa de ilustração / arte conceitual | Gemini |
| Mockup com branding | Freepik |
| Imagem para thumbnail criativa | Gemini |

---

### Bloco 5 — Vídeos com IA
**Duração: ~30 min**

**O que você vai aprender:**
- Como criar vídeos curtos para redes sociais sem aparecer na câmera
- Como transformar texto em vídeo com avatares ou narração
- Como criar vídeos de produto com cenas geradas por IA
- Ferramentas recomendadas além das principais

**Ferramentas abordadas:**
- **Kling / Runway / Pika** — geração de vídeo a partir de imagem ou texto
- **ElevenLabs** — narração com voz realista
- **CapCut com IA** — edição automatizada com legenda, cortes e música

**Fluxo de criação de um vídeo completo:**
```
1. Copy (Claude) → roteiro em tópicos
2. Imagens (Freepik/Gemini) → frames e cenas visuais
3. Voz (ElevenLabs) → narração profissional
4. Montagem (CapCut) → edição com legenda e trilha
5. Resultado → vídeo de 30-60s pronto para publicar
```

**Exercício prático:**
- Criar um vídeo de 30 segundos apresentando o projeto trabalhado na aula

---

### Bloco 6 — Juntando Tudo: Seu Projeto no Ar
**Duração: ~20 min**

**Checklist final:**
- [ ] Página criada e publicada no Lovable
- [ ] Copy revisada e inserida na página
- [ ] Imagens/fotos geradas e aplicadas no layout
- [ ] Vídeo criado e pronto para distribuição
- [ ] Tudo coerente: mesmo tom, mesma identidade visual

**Próximos passos sugeridos:**
- Conectar a página a uma ferramenta de captura de leads (Mailchimp, ConvertKit)
- Criar variações de copy para A/B test
- Gerar um pack de imagens para as redes sociais (feed + stories)
- Automatizar publicação com Make ou Zapier

## Resumo dos Frameworks Ensinados

| Framework | Onde usar |
|---|---|
| **AIDA** (Atenção, Interesse, Desejo, Ação) | Landing pages, e-mails |
| **PAS** (Problema, Agitação, Solução) | Anúncios, posts curtos |
| **BAB** (Before, After, Bridge) | Depoimentos, stories |
| **Prompt = Sujeito + Contexto + Estilo + Saída** | Qualquer ferramenta de IA |
